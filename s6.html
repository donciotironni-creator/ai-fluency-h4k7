Conținut în pregătire

Ghidul de facilitare și exercițiile pentru S6 sunt în lucru. Mai jos găsești rezumatul sesiunii din curriculum.

Despre această sesiune

MCP (Model Context Protocol) conectează Claude Code la servicii externe și la tooling-ul intern: API-uri proprii, baze de date, browser automation.

Transporturi MCP

TransportCând îl folosești
stdioProces local — cel mai comun, simplu de testat
SSEServer remote — bun pentru servicii partajate de echipă

MCP vs. script/CLI

  • Merită un server MCP când: Claude trebuie să raționeze iterativ pe output-ul unui serviciu, sau când mai multe sesiuni partajează același tool.
  • Un script/CLI e suficient când: e o operație one-shot sau outputul se citește direct cu Bash.
Suprafața de risc: un server MCP rău configurat poate expune date sensibile sau executa comenzi neintenționate. Se tratează serios în S9.
